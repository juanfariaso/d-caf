# Scripts

This section documents runnable D-CAF workflows. These pages describe how to
configure and execute a workflow; the [API Reference](../reference/dcaf/index.md)
documents the Python classes used within it.

## Available Workflows

- [Parametric Plummer Simulation](simulation.md): construct a stellar cluster
  in an evolving Plummer background potential and evolve it with D-CAF.

Additional command-line workflows can be added here as they become stable.
